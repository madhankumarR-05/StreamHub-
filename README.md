# StreamHub

Production-style Netflix-inspired streaming platform built for DevOps practice.

This project demonstrates:

- React
- Flask
- PostgreSQL
- Redis
- Git/GitHub
- Docker
- Jenkins
- SonarQube
- Trivy
- Terraform
- AWS
- Kubernetes
- Helm
- ArgoCD
- Prometheus
- Grafana
- Loki
- Load testing
- Autoscaling
- Production-style deployment and troubleshooting
